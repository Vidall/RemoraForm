# 🗺️ Mapa Geral — Remora Pages

Este é o núcleo do brainstorm. Todos os tópicos partem daqui.

## O que é o Remora Pages?

Um serviço da [[Remora Link]] onde o cliente preenche um [[Formulário Digital]], e a partir das respostas, é gerada uma [[Landing Page Personalizada]] — entregue hospedada na [[VPS Hostinger]] por uma [[Mensalidade de Hospedagem]].

A landing page é apenas a **porta de entrada**. O verdadeiro negócio está nos [[Planos e Combos]] que podem ser contratados depois, como o [[Portal Google Analytics]].

## Visão Geral do Fluxo

```
Formulário → Relatório → Landing Page → Hospedagem → Upgrades
```

Veja o detalhamento em [[Fluxo do Cliente]].
